# PIX - Application Mobile d'Investissement BRVM

PIX est une application mobile moderne conçue pour l'investissement en Afrique et sur la Bourse Régionale des Valeurs Mobilières (**BRVM**).

## Fonctionnalités clés :
- **Devise UEMOA** : Gestion intégrale du portefeuille en **Franc CFA (XOF)**.
- **4 Classes d'actifs** : Actions cotées BRVM, Obligations d'État, FCP / OPCVM et Capital-Risque (Venture).
- **Ratios boursiers** : PER (Price/Earnings), rendements de dividendes, variations de cours.
- **Passage d'ordres** : Achat et vente de titres en direct avec déduction du solde en liquidités.
- **Dépôt Mobile Money** : Intégration Wave, Orange Money et MTN MoMo.
- **Conformité & KYC** : Parcours d'identification sécurisé.

## Build APK Android
Le fichier `.apk` est automatiquement compilé par **GitHub Actions** à chaque mise à jour sur la branche `main`.
Téléchargez le dernier APK dans l'onglet **Releases** ou **Actions** du dépôt GitHub.
